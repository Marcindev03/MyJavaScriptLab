# MyJavaScriptLab

An interactive app for learning JavaScript, TypeScript, and React testing through short, hands-on lessons.

## Languages

- Repository documentation, code, comments, and commit messages use English.
- Educational content will be available in Polish and English.

## Planned learning experience

- Daily 10-minute lessons: 20% theory and 80% practice.
- Small coding exercises that gradually grow into complete features.
- On-demand hints, guided help, and code review after each exercise.
- A learning path covering unit, integration, and end-to-end testing: from plain JavaScript and TypeScript to React, API mocking, and backend testing with database mocking.

## Status

Initial project setup. The application and bilingual learning content are planned.
